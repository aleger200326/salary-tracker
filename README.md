# GEORGRAD

Локальный трекер доходов и расходов на HTML, CSS и JavaScript. Для запуска откройте `index.html` в браузере. Сборка и установка зависимостей не требуются.

## Возможности

- Дашборд с балансом, итогами за месяц и SVG-графиками.
- Добавление, просмотр, редактирование и удаление операций и категорий.
- Фильтры по месяцу, типу и категории.
- Интерфейс на русском, узбекском и английском языках.
- Операции в UZS, RUB и USD.
- Светлая и тёмная темы и пять цветов карточки баланса. Выбор сохраняется в браузере.

Валюта сохраняется отдельно для каждой операции. Переключатель пересчитывает все операции, баланс и графики в выбранную валюту по официальному курсу Центрального банка Узбекистана. Дата курса указана на дашборде. Последний полученный курс сохраняется для работы без сети; при первом запуске без сети используется встроенный курс от 17.10.2026. Данные сохраняются в `localStorage` текущего браузера под ключом `saldo-tracker-v1`.
